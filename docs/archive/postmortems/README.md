# Archived — postmortems

**Status: ARCHIVED. Non-authoritative. Historical lessons only.**

A postmortem here exists so that the durable lessons of a stopped effort survive
without anyone having to read the full research or implementation path it came
from.

Read a postmortem when you are about to re-enter the area it covers, or when you
are asked why something was stopped. Do not read them by default.

| File | Covers |
| --- | --- |
| `blocker-b-family-b-13.md` | Family B / B-S1 and Experiment #13 — PR #52 and PR #53, both unmerged; why the path was explored, why each stopped, and what remains true. |

A postmortem records history and lessons. It selects no mechanism, authorizes no
implementation, and changes no ADR status.
