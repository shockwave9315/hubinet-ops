# Changelog

The 0.2.x-0.4.x release history has been retired along with the legacy implementation it
described, as part of the 0.5-only repository cleanup. It remains available through Git
history/tags for that source line.

Hubinet Ops 0.5 has not had a numbered release yet. The current state is tracked in
[`docs/architecture/0.5-implementation-status.md`](docs/architecture/0.5-implementation-status.md):
the R0 read-only runtime is implemented and merged into `main`; it has since been
installed and genuinely exercised on a real host via two real, explicitly-authorized
manual dogfood runs of the automated Proxmox bootstrap (neither is a full bootstrap
PASS, and R0 operational activation is not yet accepted), and no 0.5 version has been
tagged/released. This file will begin recording entries from the first 0.5 release.
